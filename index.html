01
PANTALLA · CRT

Década de 1950

Cuando la computadora empezó a mostrar algo.

Los primeros sistemas trabajaban con información que una persona tenía que leer e interpretar. Las pantallas CRT introdujeron una idea sencilla pero enorme: los resultados podían convertirse en formas visibles sobre una pantalla.

La idea que permanece Cuando vemos un radar o una pantalla que muestra posiciones en tiempo real, seguimos utilizando esa misma lógica: transformar datos en una imagen que podamos interpretar rápidamente.

Referencia trabajada · Computer History Museum
02
SKETCHPAD · 1963

1963 · Ivan Sutherland

La pantalla dejó de ser una ventana y se volvió una herramienta.

Sketchpad permitió seleccionar y modificar elementos geométricos directamente con un lápiz óptico. La computadora ya no solamente enseñaba el resultado: el usuario podía construirlo y cambiarlo en la misma pantalla.

Algo que ya conocemos La idea se parece mucho a trabajar en Photoshop: seleccionas un elemento, lo mueves o lo modificas y la pantalla refleja el cambio inmediatamente.

Referencia trabajada · Sketchpad / Ivan Sutherland
03
RASTER · PÍXELES

La imagen como información

Una fotografía también puede verse como una tabla de números.

A simple vista vemos una fotografía completa. Para una computadora, una imagen rasterizada puede entenderse como una cuadrícula donde cada píxel guarda valores de color. Eso permite trabajar zonas muy pequeñas sin reconstruir toda la imagen.

Photoshop lo hace cotidiano Cuando pintamos, corregimos una imperfección o ajustamos una fotografía, estamos modificando información que pertenece a píxeles concretos.

Referencia trabajada · Adobe Photoshop / conceptos de imágenes rasterizadas
04
GPU
PROCESAMIENTO · PARALELO

Gráficos en tiempo real

Ver una imagen no basta. También tiene que responder.

Los gráficos modernos pueden necesitar muchísimos cálculos para cada cuadro. Las GPU están diseñadas para realizar grandes cantidades de operaciones gráficas en paralelo, haciendo posible una respuesta mucho más fluida.

Lo podemos notar En videojuegos, simuladores y algunas funciones aceleradas de Photoshop, la GPU ayuda a que mover, ampliar o actualizar contenido gráfico no se sienta pesado.

La graficación salió del programa y llegó a la web.

Canvas permite dibujar desde JavaScript y WebGL permite trabajar con gráficos 3D acelerados por hardware dentro del navegador. Esto abrió la puerta a experiencias visuales que funcionan directamente en una página.

04 / ALGORITMO

Del color que vemos al proceso que la computadora ejecuta.

La conversión RGB → HSV no depende de adivinar el color. Se puede describir como una serie de decisiones sencillas.

RGB → HSV5 pasos
  1. 01
    Recibir R, G y BValores entre 0 y 255.
  2. 02
    NormalizarConvertir los valores al rango 0–1.
  3. 03
    Buscar máximo y mínimoDe ahí obtenemos la diferencia, Δ.
  4. 04
    Calcular S y VLa saturación depende de Δ y el valor usa el máximo.
  5. 05
    Encontrar HLa fórmula cambia según cuál canal sea el mayor.
Δ

EL CASO ESPECIAL

¿Qué ocurre cuando Δ = 0?

Significa que el máximo y el mínimo son iguales. En la práctica, R, G y B también son iguales, así que no existe un color dominante.

RGB(50, 50, 50)→gris→Δ = 0

El algoritmo evita dividir entre cero y deja H en 0 como valor convencional, aunque el tono realmente no tiene significado para un color acromático.

Ver la función JavaScript utilizada 
function convertRGBtoHSV(r, g, b) {
  const red = r / 255;
  const green = g / 255;
  const blue = b / 255;

  const max = Math.max(red, green, blue);
  const min = Math.min(red, green, blue);
  const delta = max - min;

  let h = 0;
  let s = 0;
  const v = max * 100;

  if (delta === 0) {
    h = 0;
    s = 0;
  } else {
    s = (delta / max) * 100;

    if (max === red) {
      h = 60 * (((green - blue) / delta) % 6);
    } else if (max === green) {
      h = 60 * (((blue - red) / delta) + 2);
    } else {
      h = 60 * (((red - green) / delta) + 4);
    }

    if (h < 0) h += 360;
  }

  return [h, s, v];
}
05 / GLOSARIO

Palabras que ahora puedo explicar.

No se trata de memorizar definiciones. Son conceptos que aparecieron durante el recorrido y que ahora puedo relacionar con ejemplos que ya conozco.

01 · PÍXEL

Unidad de una imagen rasterizada que guarda información de color.

Ejemplo: ampliar una fotografía en Photoshop.
02 · FRAME BUFFER

Espacio de memoria donde se almacenan datos de los píxeles antes de mostrarlos.

Ejemplo: información de la imagen que se está preparando para pantalla.
03 · MAPEO DE ÍNDICE

Forma de localizar un píxel 2D dentro de un arreglo lineal de memoria.

Ejemplo: índice = (y × ancho + x) × 4 en RGBA.
04 · RGB

Modelo que representa un color mediante rojo, verde y azul.

Ejemplo: el color que vemos en una pantalla.
05 · HSV

Modelo que describe un color mediante tono, saturación y valor.

Ejemplo: el panel Tono/Saturación de un editor.
06 · CANAL ALFA

Valor que indica la opacidad o transparencia de un píxel.

Ejemplo: transparencia de una capa en Photoshop.
07 · COLOR ACROMÁTICO

Color sin matiz dominante porque R, G y B son iguales.

Ejemplo: RGB(50, 50, 50).
08 · DELTA

Diferencia entre el canal de mayor y el de menor valor.

Ejemplo: si máximo = 1 y mínimo = 0, Δ = 1.
09 · HTML SEMÁNTICO

Uso de etiquetas que describen qué función cumple cada parte de una página.

Ejemplo: section, nav, main, article y footer.
10 · DISEÑO RESPONSIVO

Forma de hacer que una página se adapte a distintos tamaños de pantalla.

Ejemplo: este museo cambia su distribución al verlo desde un celular.
06 / CIERRE

DESPUÉS DEL RECORRIDO

Una imagen ya no me parece solamente una imagen.

Antes podía pensar en una imagen como un archivo terminado. Después de esta unidad, entiendo que detrás de ella hay datos, píxeles, modelos de color, memoria y operaciones que hacen posible verla y modificarla.

También entendí que la graficación no consiste únicamente en crear algo bonito. Su valor está en convertir información en algo que podamos interpretar e incluso utilizar para tomar decisiones.

De eso trata este museo: de pasar de los números a una representación que podemos ver, entender y usar.
