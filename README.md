# Museo Web · Evolución Gráfica

Proyecto web final de la Unidad 1 de Graficación.

## Archivos

- `index.html` — estructura y contenido del museo.
- `styles.css` — diseño visual, responsive y accesibilidad básica.
- `assets/` — carpeta destinada a las imágenes finales del museo.

## Personalización antes de entregar

1. Cambia `[Tu nombre completo]` por tu nombre.
2. Si el profesor solicita imágenes históricas reales, colócalas dentro de `assets/` y reemplaza las ilustraciones CSS de las cinco piezas de evolución.
3. Conserva el crédito/fuente de cada imagen junto a su respectiva pieza.
4. Revisa los enlaces de la sección **Fuentes**.
5. Abre `index.html` en el navegador y comprueba la versión de escritorio y móvil.

## Nota de diseño

La página toma como referencia la estructura del prediseño entregado para el Museo Web, pero la redacción se reorganizó como un recorrido de exposición: cada sección intenta explicar una idea y conectar el contenido con ejemplos cotidianos o con Photoshop cuando la comparación ayuda a entenderla.
